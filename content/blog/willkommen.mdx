# Willkommen auf meiner neuen Website

Dies ist der erste Blogpost auf meiner überarbeiteten Website. Ich habe das System erheblich vereinfacht:

## Was ist neu?

- **Keine Datenbank mehr** - Alle Inhalte werden als MDX-Dateien im Repository gespeichert
- **Static Site Generation** - Schnellere Ladezeiten und bessere Performance
- **Frontmatter für Metadaten** - Strukturierte Informationen direkt in den Dateien
- **Vollständige TypeScript-Unterstützung** - Bessere Entwicklererfahrung im IDE

## Mathematische Formeln funktionieren weiterhin

Die Quadratische Formel: $x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$

Oder als Blockformel:

$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$
