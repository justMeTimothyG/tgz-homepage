## Aufgabe 2
<Exercise>
<Task>
Bilden Sie für die folgenden Geschäftsvorfälle der Brauerei „Duff Beer“ die entsprechenden Buchungssätze:
<br />
**Geschäftsvorfälle:**
<NumberedList variant="lower-alpha">
<li>Kauf einer Abfüllanlage im Wert von 75.000 € per Banküberweisung.</li>
<li>Brauzutaten werden im Wert von 10.000 € auf Ziel gekauft.</li>
<li>Bezahlung der Ware aus Geschäftsvorfall b) in bar.</li>
<li>Barabhebung von der Bank in Höhe von 2.000 €.</li>
<li>Barverkauf eines ausgedienten Lieferwagens für 5.000 €.</li>
<li>Aufnahme eines Kredits über 100.000 €. Die Gutschrift erfolgt auf dem Bankkonto.</li>
<li>Banküberweisung eines Kunden zur Begleichung einer Forderung im Wert von 2.400 €.</li>
<li>Eine Lieferantenverbindlichkeit über 3.500 € wird in ein langfristiges Darlehn umgewandelt.</li>
<li>Die Brauerei erhält Waren im Wert von 45.000 €, wovon Waren im Wert von 40.000 € auf Ziel gekauft werden und 5.000 € sofort in bar bezahlt werden.</li>
</NumberedList>
</Task>
</Exercise>

### Lösung

|  | Soll | an | Haben | Betrag |
|---|---|---|---|---|
| a) | Maschinen | an | Bank | 75.000 € |
| b) | RHB | an | Verbindlichkeiten aus LuL | 10.000 € |
| c) | Verbindlichkeiten aus LuL | an | Kasse | | 10.000 € |
| d) | Kasse | an | Bank | 2.000 € |
| e) | Kasse | an | Fuhrpark | 5.000 € |
| f) | Bank | an | Darlehen | 100.000 € |
| g) | Bank | an | Forderungen | 2.400 € |
| h) | Verbindlichkeiten aus LuL | an | Darlehen | 3.500 € |
| i) | RHB | an | Verbindlichkeiten aus LuL | 40.000 € |
|   | RHB | an | Kasse | 5.000 € |


## Aufgabe 3

<Exercise>
<Task>
Interpretieren Sie folgende Buchungssätze und bilden Sie die entsprechenden Geschäftsvorfälle. 
</Task>
</Exercise>

|  | Soll | an | Haben | Betrag |
|---|---|---|---|---|
| 1) | Kasse | an | Forderungen aus L.u.L. | 10.000 € | 
|    | Bank | an | Forderungen aus L.u.L. | 10.000 € |
| 2) | Darlehen | an | Bank | 8.000 € |
| 3) | RHB | an | Bank | 5.000 € |
|    | RHB | an | Verbindlichkeiten aus L.u.L. | 10.000 € |
| 4) | Verbindlichkeiten aus L.u.L. | an | Bank | 2.000 € |
|    | Verbindlichkeiten aus L.u.L. | an | Kasse | 500 € |
| 5) | Maschinen | an | Bank | 23.000 € |
| 6) | Bank | an | Darlehen | 15.000 € |

### Lösung

1) Zahlung einer Forderung eines Kunden mit jeweils 5.000 in Bar und 5.000 per Überweisung
2) Tilgung eines Darlehens per Banküberweisung iHv 8.000
3) Brauzutaten iHv. von 15.000 werden gekauft, wobei 5.000 sofot per Überweisung bezahlt werden und der Rest auf Ziel 10.000
4) Bezahlung einer Verbindlichkeit iHv 2.500 wobei 500 in bar bezahlt werden und 2.000 werden über Überweisung bezahlt
5) Kauf von Maschinen per Banküberweisung iHv 23.000
6) Aufnahme eines Darlehens iHv 15.000. Das Guthaben wird auf die Bank bezahlt
