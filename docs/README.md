## Component Usage Patterns

### Educational Content Types → Component Mapping
| Content Type | Primary Component | Alternative |
|--------------|------------------|-------------|
| Concept emphasis | Alert (info/tip) | Exercise wrapper |
| Warnings/cautions | Alert (warning/error) | - |
| Code evolution | CodeComparison | Alert with code blocks |
| Interactive learning | InteractiveDemo | Exercise with interaction |
| Practice problems | Exercise system | Alert with prompts |
| Math tools | GcdCalculator, LcmCalculator | InteractiveDemo |

### German Educational Context
- Use formal "Sie" form in instructional components
- Include mathematical notation (√, ², ³) where appropriate
- Maintain educational progression and clear explanations
- Consider accessibility and mobile learning contexts
